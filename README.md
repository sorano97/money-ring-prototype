# Money Ring プロトタイプ

おこづかいアプリ「Money Ring」の既存機能に、新機能「かう？まつ？」を組み込んだWebプロトタイプです。

> ほしい気持ちを、考える力に。

## 開き方

`index.html` をブラウザで開くだけで動きます。ビルドやサーバーは不要です。

- PCでは画面中央にスマホの枠が表示され、その中で操作できます
- スマホで開くと全画面で表示されます

## 機能

### 既存機能（Money Ringの画面を再現）

| 画面 | できること |
|---|---|
| ホーム | お金の合計、カード／現金の残高、おこづかい帳の最新記録、「かう？まつ？」への入口 |
| おこづかい帳 | 月の切り替え、すべて／ふえた／へったの絞り込み、ふえた・へったの比較、記録の追加 |
| ミッション | クリア件数（今週・今月・すべて）、チェックまち／やりなおし／今日／つぎのミッション |
| お知らせ | 運営からのお知らせ、保護者からの依頼、未読バッジ |
| メニュー | 通知設定、各機能への入口、デモ操作 |

### 新機能「かう？まつ？」

| 機能 | できること |
|---|---|
| ほしいものリスト | 商品名・価格・理由・優先度・目標日を登録。残高と比べて「あと〇円」と1週間あたりの必要額を表示 |
| がまんしたものリスト | 見送ったものと理由を記録。「やっぱりほしい／もうほしくない」を選択（見送った金額は貯金として扱わない） |
| おかいものシミュレーター | 「いま買う」「今回は見送る」の残高と、ほしいものまでの残り金額を比較 |
| おかいもの振り返り | まったもの・買ったものについて3つの質問とひとことメモで振り返る |
| 親子でおかいもの相談 | ほしいものを保護者に共有し、メッセージでやりとり |

### 機能どうしの連携

- 「かう」「買った」→ 残高が減り、おこづかい帳に「へった」として記録
- ミッションクリア → ごほうびがカードに入り、おこづかい帳とお知らせに反映
- 保護者のコメント → お知らせに通知

## プロトタイプとしての注意

- 表示しているデータはすべて見本です
- 入力内容はブラウザの localStorage にだけ保存されます（サーバーなし・端末間で共有されません）
- ユーザーテスト用に、以下のデモ操作を用意しています
  - メニュー →「おこづかい +500円」「さいしょに もどす」
  - ミッションのチェックまち →「（デモ）OKする」「（デモ）やりなおし」
  - 親子相談 → 書く人を「じぶん／おうちの人」で切り替え
